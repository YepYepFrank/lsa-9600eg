# 传感器单元验收脚本 `sam_check.py`

> **给谁用**：到货检验 / 装柜前，把一套传感器单元（局放超声、气体、温湿度、ALS10 弧光 + 双目摄像机）接到一台 EG 上，几分钟内确认每一路都通。
> **在哪跑**：EG（X26A，Ubuntu）本机。只要系统自带的 `python3`（3.8+），**不装任何东西、不联网、不改 EG 配置**。

## 1. 接线

| 设备 | 接到 EG | 约定 |
|---|---|---|
| 局放（超声）、气体、温湿度、弧光 ALS10 | COM2（RS-485，`/dev/ttyS1`，BIOS 里设成 485） | 9600 8N1；从站 局放 2、气体 3、温湿度 4、弧光 5（厂家出厂设好） |
| 双目摄像机 | LAN1 | 摄像机 192.168.1.19，EG LAN1 192.168.1.1/24（摄像机出厂地址，不改） |

USB 转 485 也行：`--port /dev/ttyUSB0`（或 `/dev/serial/by-id/…`）。

## 2. 跑

```bash
# 拷到 EG 上（U 盘或 scp），然后：
sudo python3 sam_check.py --sn <传感器单元编号>
```

依次做三段，最后出汇总和结论：

1. **传感器**：每台问 5 轮，看应答率、时延、读数范围、状态 / 故障位。有传感器不应答时**自动扫 1–32 号地址**，看是不是地址设错了、还是总线根本不通。
2. **功能试验**（人配合，每项回车开始、输入 `s` 跳过）：
   - 弧光：手机闪光灯 / 强光手电正对探头照 2–3 秒 → 弧光强度要涨（缺省 ≥ 1 个百分点，`--arc-rise` 调）；
   - 温湿度：哈气 / 手握探头 → 湿度涨 3 %RH 或温度涨 0.5 ℃；
   - 局放：探头前搓手 / 揉塑料袋 / 超声发生器 → 放电量涨 3 dBμV 或放电次数 > 0；
   - 气体：一支香 / 吹灭的火柴的烟靠近进气口 → 涨 20 ppm（可以留到现场做）。
3. **摄像机**：restv1 登录、设备信息、两路流地址、热像全画面温度、两路抓拍（JPEG 存进报告目录，拷出来看一眼画面对不对）；RTSP **可见光 / 热像 × 主 / 子码流**逐路拉 4 秒：鉴权、收包、关键帧、分辨率、帧率、码率。热像通道出现高清分辨率会提示「两路接反」。

结论只有「通过 / 不通过」，「注意」项不算不通过但要看一眼。报告和抓拍在 `./sam-check-<编号>-<时间>/`。退出码：通过 0、不通过 1、参数 / 环境问题 2。

### 连续换测（一台 EG，热插拔换一套测一套）

```bash
sudo python3 sam_check.py --loop            # 想快一点：加 --no-func 不做功能试验
```

- 开始时停一次转换程序，**退出（输入 q 或 Ctrl+C）时才把转换程序起回来**。
- 每一套：换好传感器单元 → 输入编号（扫码枪直接扫；直接回车自动编 `unit-001`…）回车 →
  脚本先清掉 EG 上摄像机地址的 ARP（新摄像机同一个 IP、MAC 不同），**最多等 120 s**（`--wait` 改）直到四路传感器都应答、弧光过了上电启动抑制、摄像机 HTTP / RTSP 端口开了 → 照常全测 → 打一块大字结论：
  ```
  ================================================================
    SAM-0002   不通过
    [不通过] 温湿度（从站 4）：5 轮全没读到：没有应答
    [不通过] RTSP · 热像主码流：…
  ================================================================
  ```
- 摄像机的序列号 / MAC 跟上一套一样会给「注意」：摄像机没换，或者还在测旧的。
- 结果：`sam-check-batch-<时间>/summary.csv`（时间、编号、结论、不通过项、注意项、摄像机序列号、MAC、报告路径，Excel 直接打开），每套一个子目录放报告和两张抓拍。

### 摄像机口令

**缺省用摄像机出厂账号**（写在脚本 `FACTORY_CAM` 里：RTSP 取流用 admin，restv1 接口用另一套普通账号；admin 登不了接口），到货检验不用输口令。
摄像机改过口令的，用环境变量传，或 `--local-yaml /opt/lsa-eg/config/local.yaml` 读那台 EG 配好的：

```bash
sudo LSA_CAM_PASS='…' LSA_CAM_REST_PASS='…' python3 sam_check.py --rest-user <接口账号> --cam 192.168.1.19
```

输出和报告里不带口令。

### 常用参数

| 参数 | 用途 |
|---|---|
| `--no-func` | 不做功能试验（无人值守、批量） |
| `--no-cam` / `--cam-only` | 不查摄像机 / 只查摄像机 |
| `--only th,arc` | 只查这几路（`pd gas th arc ir`） |
| `--slave th=14` | 某一路地址不是缺省 |
| `--scan` / `--scan 1-247` | 主动扫地址 |
| `--ir` | 也查 SAM 自带红外（从站 1；S19 没有） |
| `--rounds 20` | 多问几轮，看通信稳不稳 |
| `--rtsp-secs 10` | 每路拉流时间加长（I 帧间隔长时） |

## 3. 注意

- EG 上的转换程序（容器 `lsa-eg-conv`）占着串口：脚本**先停、跑完自动起**（Ctrl+C 也会起）。如果脚本被 `kill -9` 了，手工 `sudo docker start lsa-eg-conv`。
- 已经接入子站的 EG 上跑，停转换程序那几分钟子站会看到这台 SAM 通信中断 —— 到货检验用**没接入**的台架 EG。
- 摄像机 restv1 最多 2 个会话：EG 的 eg-video 占一个，再开着摄像机网页 / 调试工具就会登录失败（19999），关掉再跑。
- 强光可能触发 ALS10 弧光告警，出厂是**锁存模式**：功能试验后脚本会提示，按厂家方法复位（或给传感器单元断电重启）再装柜。
- 局放只配超声（S19）：地电波读出 187、特高频读出 269 是「没装」的固定值，正常。

## 4. 常见现象

| 现象 | 处理 |
|---|---|
| 全部「没有应答」，扫地址也一个都没有 | A+/B- 接反、传感器没供电、COM2 BIOS 没设 485、波特率不是 9600 |
| 某一台「没有应答」，扫地址扫出一个「不认识」的 | 那台地址设错了：`--slave <键>=<地址>` 验一下，再让厂家改回约定地址 |
| 「CRC 错」 | 干扰 / 终端电阻 / 两台同地址 |
| 弧光「启动抑制中」 | 刚上电，等半分钟再跑 |
| RTSP「401 鉴权失败」 | RTSP 只认 admin，口令不对 |
| RTSP「SETUP 453 / 454」 | 摄像机会话满了（EG 的 mediamtx 也在拉） |
| 热像全画面最高 = 最低 | 镜头盖没摘 / 画面没内容 |

# 0.10 浏览器核对清单（子站 0.10 + EG 0.2.0）

脚本已经核过接口和数据（`docs/评审记录.md`「一键安装 0.10」一节），这份清单只列**要人眼看的地方**：页面上的字、颜色、角标和布局。看完逐条打 ✓，不对的记下页面、柜号和截图。

**账号**：请自己查，本清单不写口令。

- 子站：SP-VM 上的 `/opt/lsa9600sp/初始账号口令.txt`，用「业务管理员 admin」。如果首次登录后改过口令，就用改后的。
- EG 本地管理页：各 EG 上的 `/opt/lsa-eg/initial-password.txt`。改过口令就用改后的。

## 有问题时

记下页面、柜号和时间（精确到分钟），截图。不用自己改配置：能力改错了，在「能力」页签把它改回「来源 model」即可（下拉选回原值，或在接口上用 null 退回）。

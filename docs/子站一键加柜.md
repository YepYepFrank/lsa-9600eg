# 子站一条命令接 EG（一键加柜，0.17.4 起；0.18.0 起按舱室单元）

> 给子站部署手册用的一节（子站部署手册「一键加柜」指向这里）。脚本 `/opt/lsa9600sp/join-egs.sh`，由一键安装文件 `--role sp` 装上，和 `upgrade-egs.sh` 放在一起。EG 侧的授权与安全见 EG 部署手册 §4a、§6c；设计见 EG 库 `docs/一键加柜方案.md`，舱室单元见前端库《舱室 EG 架构调整方案》v0.5 §3.2 / §8.1。
>
> 做法：EG 上只动一次手（装软件时带一行 join-key，可以在进场前的库房做），其余全在子站完成：建本地实体、打配置、推送生效、设转换程序、撤隧道。老办法（现场笔记本 SSH 进 EG，手工 `--sp-key`、provision、pack、拷文件、`install.sh`）照旧能用。
>
> **0.18.0 起一个电气舱室一台 EG**：EG 名 `EG-<柜号>-<字母>`（如 `EG-AH05-A`），**单元号**就是 EG 名去掉 `EG-`（`AH05-A`）。照旧一柜一台的柜（`model.site.yaml` 的 `legacyEg`）单元号就是柜号（`AH05`），用法和 0.17.4 一样。下文的「单元号」两种都指。

## 1. 一次性准备（子站主机）

```bash
sudo bash /opt/lsa9600sp/join-egs.sh --keygen
```

- 生成隧道 key `keys/eg-tunnel_ed25519`；升级 key `keys/eg-upgrade_ed25519` 已经有（批量升级生成过）就复用，没有就一起生成。都在 `/opt/lsa9600sp/keys/`（root，600）。
- 子站地址取 `docker/.env` 的 `SP_HOST_IP`；取不到或者不对，用 `--sp-addr <子站站内地址>` 给（记住，以后不用再给）。
- 打印一行 **join-key**：
  ```
  LSAJOIN1 192.168.77.20 ssh-ed25519 AAAA…（隧道） ssh-ed25519 AAAA…（升级） 3f2a9c1e
  ```
  里面**只有公钥**，没有任何私密信息：打印、发微信、贴在工单里都没关系。最后 8 位是校验，抄错、少粘一截时 EG 会直接拒绝。
- 重跑 `--keygen` 不会换 key，打印的还是同一行。

## 2. EG 上（一次，库房或现场）

```bash
sudo bash LSA-9600SP-<版本>.run --role eg --lan1 <摄像机网口> --join-key '<上面那一行>'
```

- 整行要加**单引号**。单网口的 EG 不给 `--lan1`。
- 装完就是「**待接入**」：本地 TB 起着，浏览器开 `http://<EG 的 LAN2 地址>/` 是一张只读的待接入页 —— 授权的子站、本机各网口的 IP / MAC、软件版本、本地 TB 起没起，以及子站上要执行的下一条命令。页面上没有任何密钥，也没有任何操作。
- `sudo bash /opt/lsa-eg/install.sh --status` 也会显示「接入：待接入 —— 已授权子站 192.168.77.20」；接入以后显示「接入：已接入子站 192.168.77.20（EG-AH05-A · 柜 AH05 断路器室）」。
- 已经装好的 EG 也可以只补授权：`sudo bash /opt/lsa-eg/install.sh --join-key '<那一行>'`（等于 `--sp-key` 加 `--upgrade-key`，两把 key 都只认子站地址来的连接）。
- 已接入别的子站的 EG 给了别的子站的 join-key：拒绝，要换子站加 `--force`。
- **接舱室单元要 EG 0.7.0 起**（老 EG 读不了舱室单元的 eg.yaml schema 2）；照旧一柜一台的柜 0.17.4（EG 0.6.3）起就行。

## 3. 子站上接一台

```bash
# 先看能不能接（只看，不改任何东西）
sudo bash /opt/lsa9600sp/join-egs.sh --unit AH05-A --eg 192.168.10.25 --plan

# 接入
sudo bash /opt/lsa9600sp/join-egs.sh --unit AH05-A --eg 192.168.10.25
# 带转换程序（缺省串口 / 传感器）
sudo bash /opt/lsa9600sp/join-egs.sh --unit AH05-A --eg 192.168.10.25 --conv auto
# 指定串口、传感器、从站地址
sudo bash /opt/lsa9600sp/join-egs.sh --unit AH05-A --eg 192.168.10.25 --conv-serial /dev/ttyUSB0 --sensors pd,gas,temperature --addr pd=2,gas=3
# 照旧一柜一台的柜：单元号就是柜号
sudo bash /opt/lsa9600sp/join-egs.sh --unit AH09 --eg 192.168.10.29
```

`--eg` 是 EG 的 **LAN2 地址**（子站连得到的那个）。单元要是子站模型里有的：柜不在 `model.yaml` 就先加柜再 `scripts/up.sh --prod`；柜还照旧一柜一台、要按舱室接，就先拆柜（§4）。

**步骤**（每步都记在 `/var/log/lsa9600sp/eg-join/<单元号>-<时间>/run.log`）：

| 步 | 做什么 | 重跑时 |
|---|---|---|
| 预检 | 单元在子站模型里；这个单元没有别的 EG 在线（有就要 `--force`）；EG 的升级入口认得上、版本够（舱室单元 0.7.0 起，照旧一柜一台 0.17.4 起）；EG 的 hello `unit=`（见下）；授权的子站就是本机；隧道账号认得上 | — |
| 1 建实体 | `provision-eg.sh --unit <单元号>`（照旧一柜一台的 `--cabinet <柜号>`）`--ssh lsa-sp@<EG> --ssh-key keys/eg-tunnel_ed25519 --eg-url http://<EG>` | 幂等；隧道已撤（已接入本单元）就跳过 |
| 2 打配置包 | `pack-eg.sh --sp <子站> --only <单元号>`，eg.yaml + sp-ca.pem 打成 tar.gz | 照做（几秒） |
| 3 推送并生效 | 经升级入口 `put-config`、`apply-config`；EG 在后台换上配置、起全部服务、自查（7 个容器、agent 连上子站），**失败自己换回**（原来待接入的回到待接入）；子站每 10 s 查一次 | 配置和 EG 上的一模一样就跳过，不重启 |
| 4 等在线 | 子站 eg-list 看到这台上送正常、配置已生效（最多 3 分钟） | 照做 |
| 5 转换程序 | 给了 `--conv` 等参数才做，经入口的 `conv`（参数白名单，见 EG 部署手册 §4a） | 照做（install-conv.sh 只改给了的项） |
| 6 撤隧道 | `drop-tunnel`：删掉 EG 上的隧道账号 lsa-sp；**升级授权留着**（以后批量升级用） | 照做 |

**预检看 EG 的 hello `unit=`**（舱室 EG 方案 §3.2）：

| EG 报的 | 结论 |
|---|---|
| 没有单元（待接入的新机） | 放行 |
| 就是 `--unit` 给的单元 | 当重装，放行（各步已做的会跳过） |
| 别的单元 | 拒绝；确认要把这台改接过来加 `--force`（EG 那边同样要 force 才肯换） |
| 只报 `cabinet=`、没有 `unit=`（EG 0.6.x） | 当照旧一柜一台，单元号取柜号 |

运行时认身份靠令牌，子站不看 hello；hello 只给预检用。

**结果**：最后一张汇总表，每步「完成 / 跳过 / 失败 / 没做」。失败就停在那一步，打印原因和「修好后原样重跑这条命令」—— 前面已做完的会跳过。

常见的失败：

| 提示 | 原因 / 怎么办 |
|---|---|
| 柜号 AH05 不在子站的 model.yaml 里 | 先在 model.yaml 加柜，再跑 up.sh |
| 子站上没有单元 AH05-A：这面柜还照旧一柜一台 | 先拆柜（§4），或者单元号写错了 |
| 柜 AH05 已经拆成舱室单元 | 按单元接：`--unit AH05-A`，或 `--cabinet AH05` |
| 单元 AH05-A 已经有别的 EG（…）在线 | 确认是换 EG，加 `--force` |
| 升级入口没授权 | EG 装的时候没带 `--join-key`，或者带的是别的子站的：EG 上重跑 `install.sh --join-key '<本子站那一行>'` |
| EG 版本太老：接舱室单元要 EG 0.7.0 起 | EG 先升到 0.7.0（批量升级或手工） |
| 这台 EG 已接入单元 AH03-A | 一台 EG 只接一个单元；确认要改接加 `--force` |
| 隧道账号认不上 | 隧道已撤（接入过）或 join-key 是别的子站的：EG 上重跑 `install.sh --join-key` |
| 推送并生效失败、已自动换回 | 看汇总里的原因和 EG 上的任务日志（汇总前打印最后 30 行） |

## 4. 一面柜的全部单元；拆柜

```bash
# 已拆好的柜：全部单元依次接（--eg 按单元给地址，键可以只写字母；没给的单元用子站记的地址）
sudo bash /opt/lsa9600sp/join-egs.sh --cabinet AH05 --eg A=192.168.10.25,B=192.168.10.26 [--plan]

# 拆柜：照旧一柜一台 → 舱室单元，一条命令走完
sudo bash /opt/lsa9600sp/join-egs.sh --split AH05 --eg A=192.168.10.25,B=192.168.10.26 --plan    # 先预检
sudo bash /opt/lsa9600sp/join-egs.sh --split AH05 --eg A=192.168.10.25,B=192.168.10.26
```

`--cabinet` 一台失败不影响后面的单元，最后汇总、给出失败那台的重来命令。

**拆柜**照子站部署手册 §5b 的推荐顺序做，把断数窗口压到最短：

1. **预检**（这一步什么都不改）：`--eg` 里每台 EG 要 0.7.0 起、待接入；**这面柜原来那台**也可以改作一个单元（它要先在 EG 上重跑一次 `install.sh --join-key '<本子站那一行>'` 补回隧道授权）。有一台不能接就整个不开始。原来那台不在 `--eg` 里会提醒：拆柜后它的令牌作废、上送被拒。
2. 备份 `tb/model.site.yaml`（备份在 `/var/log/lsa9600sp/eg-join/split-<柜号>-<时间>/`），从 `legacyEg` 去掉这面柜（`unitIndex` 等别的不动），跑 `scripts/up.sh --prod`：建 `EG-<柜>-A/B…`、把 SAM / 电表改挂到各单元（0.18.1 起没有颗粒物 PM6）（设备与历史不动）、旧 `EG-<柜>` 归档、旧令牌作废。**从这一刻起这面柜断数**。
3. 等子站 eg-list 列出这面柜的单元，马上逐台接入（同 §3；原来那台带 force 改作单元）。没在 `--eg` 里的单元不接，子站上显示「未接入」，不算故障。
   原来那台装着转换程序的：换上新 eg.yaml 时 EG 发现单元变了，会自动把转换程序配置里已经不在本单元的设备名改挂到本单元的 SAM、重启转换程序（clientId 换成 `lsa-conv-<单元号>`），从站地址、开关、串口不动（EG 0.7.0，`install-conv.sh --rebind`）。拆柜一般要重新接线：每个舱室的传感器接到本舱室 EG 的 COM2，接好后在各台 EG 上按实际接线调一遍（`--sensors` / `--addr`，见《转换程序硬件联调步骤》）。
4. 汇总：各单元的结果、**断数窗口**（EG 0.7.1 起：up.sh 开始 → 最后一台**第一次**上送正常，各台各自多久恢复也列出来；「全部配置生效」另报一行 —— 配置生效要再等约 1–2 分钟，不影响上送。单元是一台接完再接下一台，单元越多窗口越长：两个单元实测约 1–3 分钟）。拆完的标准：网关页每个单元都在线、`check.sh` 的「舱室单元」与「配置下发」都正常。

up.sh 失败就停下：`model.site.yaml` 已改（原来的在日志目录），修好后重跑 `up.sh --prod`，再 `--cabinet <柜号> --eg …` 接单元。不要先拆柜、隔几天再去换 eg.yaml：这几天这面柜一直没数据。

## 5. 一次预检一批

```bash
sudo bash /opt/lsa9600sp/join-egs.sh --from-file 单元清单.txt --plan
```

清单每行「单元号 EG地址」，`#` 开头是注释：

```
# 3 号站一期
AH05-A 192.168.10.25
AH05-B 192.168.10.26
AH09   192.168.10.29
```

逐台给出「能 / 否」和结论，只做预检，不改任何东西；全都能接时退出码 0。**真接入用 `--unit` / `--cabinet`**。

## 6. 接入以后

- 网关页上这台在线、配置已生效；EG 本地页变成正常的管理页，标题带舱室（如「AH05 1#出线柜 · 断路器室」）。
- 批量升级照常：`sudo bash /opt/lsa9600sp/upgrade-egs.sh --run <新 .run> --only AH05-A`（按单元号；升级 key 就是 join-key 里那一把）。
- 以后要再建实体（改设备清单等）：EG 上重跑 `install.sh --join-key '<那一行>'` 补回隧道授权，再在子站重跑 join-egs.sh（配置没变的步骤会跳过）。

## 1. 现有入口（读下来的结论）

- **装**：每台 `sudo bash LSA-9600SP-<版本>.run --role eg --lan1 <网口> --join-key '<一行>' --yes`。`.run` 自解压到 `/var/tmp`（要 `.run` 大小 + 512 MB），`setup.sh` 先 `sha256sum -c` 全部文件，再进 `install.sh`；带 `--join-key` 时装完是**待接入**（起待接入页 80 口，`install.sh --status` 显示「接入：待接入 —— 已授权子站 X」）。`--yes` / 非终端时不问任何东西。
- **join-key**：子站 `join-egs.sh --keygen` 打印（幂等、key 已有不重新生成）；7 段，最后一段是前 6 段 sha256 的前 8 位，EG 上校验。两把 key 的 `from=` 锁到子站地址。
- **接入**：子站 `join-egs.sh --unit <单元> --eg <EG 的 LAN2 地址>`；`--from-file <清单> --plan` 能一次预检一批（每行「单元号 EG 地址」）。
- **批量升级** `upgrade-egs.sh` 走 `lsa-upg` 升级入口，要 EG 已装过软件、授权过 —— **新机用不上**，只能走维护账号 `lsaadmin`。
- 这三个脚本都没有「改网口地址」：手册 §2a 是让人在 EG 上手敲 netplan。现场 83 台每台都从同一个 `.250` 改成正式地址，正是要自动化的那一步。

## 2. 现场流程（一台一台上架，子站主机上一条命令连续做）

```
sudo bash /opt/lsa9600sp/field-install-egs.sh --plan s19-站A.tsv --run /data/LSA-9600SP-0.18.1.run
```

```
 屏幕：  等下一台出现在 192.168.1.250 …（接好 LAN2、上电即可；q 回车结束）
 ┌─ 阶段 A：在 .250 上（一次只有一台，串行，约 1 分钟）─────────────────────────┐
 │ 1 连上 .250（口令只在开头问一次）→ 读主机名 lsaeg-<SN>、网口、MAC、系统版本      │
 │ 2 按 SN 在分配表里找到这台的正式地址 / 单元号；屏幕上确认（--yes 不问）          │
 │ 3 写 netplan：LAN2 正式地址 + 网关，LAN1 192.168.100.1/24；先 netplan generate   │
 │   校验，再定一个「180 s 后自动换回 .250」的保险，后台 netplan apply              │
 │ 4 在正式地址上连回来、核对是同一台（同一把主机密钥、同一个主机名）→ 撤掉保险     │
 └──────────────────────────────────────────────────────────────────────────────┘
        .250 空出来了 → 立刻回到「等下一台」；这台转到后台做阶段 B
 ┌─ 阶段 B：在正式地址上（后台，可几台同时，缺省 --parallel 3）────────────────────┐
 │ 5 推 .run（3 GB）到 /var/tmp/lsa-field/，断了接着推（按已收字节续传），            │
 │   推完 EG 上 sha256 与子站算的一致才往下                                         │
 │ 6 EG 上后台跑 .run --role eg --lan1 <LAN1> --join-key '<子站那一行>' --yes       │
 │   （systemd-run 起，SSH 断了照样装完）；每 10 s 查一次                            │
 │ 7 核对：install.sh --status 是「待接入 —— 已授权子站 <本子站>」、待接入页 80 口通  │
 │   → 删掉 EG 上的 .run 拷贝 → 记「待接入」                                        │
 └──────────────────────────────────────────────────────────────────────────────┘
 结束（q 或分配表做完）：等后台的做完 → 汇总表 → 写出 join 清单（单元号 地址），
 下一步：join-egs.sh --from-file <清单> --plan 一次预检，再逐台 join-egs.sh --unit … --eg …
```

**节拍**：阶段 A 约 1 分钟/台（大部分是等 netplan 生效和 SSH 重连），阶段 B 约 5–8 分钟/台在后台跑。上架的人插好一台、屏幕上确认，就可以去插下一台，不用等安装。

## 3. 输入：站点分配表

纯文本（TSV 或空格分隔，`#` 开头是注释；Excel 另存为「文本文件(制表符分隔)」即可），每台一行：

```
# SN            LAN2 正式地址/前缀    网关           单元号     LAN1 网口（可空 -）
X26A2410001     192.168.10.31/24      192.168.10.1   1G-A       enp1s0
X26A2410002     192.168.10.32/24      192.168.10.1   1G-B       -
```

- **SN** 用来认机器：脚本从 `.250` 上读主机名 `lsaeg-<SN>`，去掉前缀在表里找；找不到就停（打出主机名，让人补表或 `--sn` 手工指定）。
- **单元号**只用来写进最后的 join 清单（`join-egs.sh` 用），本脚本不解释它；可以先写 `-`，之后接入时再定。
- 表里地址重复、和 `.250` 同址、SN 重复：开始前就拒绝。
- **网关**整表一样时可以用 `--gw 192.168.10.1` 代替这一列（列里写 `-`）。

### LAN1 网口名怎么定

1. 分配表第 5 列有就用它（从《出厂记录表》的「LAN1 网口名」抄）；
2. 没有就自动认：X26A 只有两个 `en*` 网口，**持有 192.168.1.250 的那个是 LAN2，另一个就是 LAN1**（和手册 5.1「插 LAN2 认网口」同一个道理，而且这时 LAN2 正是我们连进来的口，不会认错）；
3. 两者都有但对不上 → 停下（厂家记录错了，或者 LAN1/LAN2 插反了）；`en*` 网口不是正好两个 → 停下，要求表里写明。
4. 每台的两个网口名、MAC 都记进日志和汇总，可以和《出厂记录表》对。

LAN1 地址缺省 `192.168.100.1/24`、`ignore-carrier: true`（手册 §2a：每台 EG 都一样、摄像机统一 192.168.100.64）；`--lan1-addr <地址/前缀>` 换网段、`--lan1-addr none` 不配。**摄像机出厂地址是 192.168.1.x**（和 LAN2 出厂临时地址同一段），接到 LAN1 之前要先在摄像机管理页改到 LAN1 那一段（缺省 192.168.100.64/24，NTP 设 EG 的 LAN1 地址，部署手册 §5a）。

## 4. 口令与密钥（口令不落盘）

- 开头问一次 `lsaadmin` 的口令（不回显），只放在脚本进程的内存 / 环境变量里：
  - SSH 用 `SSH_ASKPASS` + `SSH_ASKPASS_REQUIRE=force`（Ubuntu 24.04 的 OpenSSH 9.6 支持）：askpass 助手是一个两行的小脚本，从环境变量里取，文件里没有口令；
  - 每台只认证一次：`ControlMaster` 复用连接；
  - `sudo -k -S -p ''`：口令从 stdin 喂给 sudo（`printf` 是 bash 内建，不出现在进程参数里）。
- 不往 EG 上放任何 key、不改 `lsaadmin`、不改 sshd 配置（「SSH 允许口令登录」留给接入后的安全提醒去管，不在本脚本范围）。
- **主机密钥钉住**：第一次在 `.250` 连上时记下这台的主机密钥，按 `HostKeyAlias=lsaeg-<SN>` 存进这台自己的 known_hosts；之后在正式地址上严格核对。这样 83 台轮流用 `.250` 不会互相报「主机密钥变了」，改完地址连回来的一定是同一台。
  - 顺带查**克隆没换主机密钥**（手册 §8 第 3 步漏做）：和已做过的某台密钥一样 → 提醒（不拦）。主机名和已做完的另一台一样（克隆没改主机名）、但 machine-id 不同 → 停下。
- 口令也可以用环境变量 `LSA_EG_PW` 给（只给自动化测试用；手册里写交互输入）。

## 5. 安全阀与可续跑

| 情况 | 处理 |
|---|---|
| 新地址连不回来（前缀 / 网段写错、交换机 VLAN 不对） | EG 上的保险 180 s 后自动换回原来的 netplan（又回到 `.250`），脚本报「改地址没成功，已自动换回」，这台记失败；修好表后它再出现在 `.250` 时重做。**保险扛得住重启**：写成 `/etc/systemd/system/lsa-field-revert-<令牌>.timer/.service` 并 enable（`OnActiveSec=180s`，开机时 timer 重新启动、重新计 180 s），180 s 内拔电重启照样换回；确认（连回来核对通过）时连 unit 一起删。换回和确认用同一把 flock 互斥，换回过的留 `reverted-<令牌>`，之后的确认一律判失败 |
| 改地址失败的那台还没换回时 | 它这时还在新地址上，`.250` 看着是空的 —— **不算拔走**：屏幕提示「先别插下一台」，等它换回 `.250` 再拔走，或者过了换回时间 + 90 s 余量（`LSA_FIELD_HOLD_MARGIN_S`）才看下一台；`r` 回车可以手工放行 |
| 网关写错、但地址在对的网段 | 子站和 EG 同一网段，照样连得回来，**不会**换回（VM 实测）；改好地址后在 EG 上看网关应不应答 ARP，不应答就提醒「网关写错了？」，照装（EG 只和同网段的子站通信，不影响装和接入；改的话在 EG 上改 netplan 的 via） |
| 正式地址上已经有别的机器应答 | 改地址前先探一下：22 / 80 口有应答就停下（地址冲突） |
| .250 上不止一台（两台新机同时接着，或站内网就是 192.168.1.x、有别的设备占着 .250） | 连上以后广播问 3 次 ARP（要 root）：有 `arping` 用它，没有（Ubuntu Server minimal 就没有）用 python3 发原始 ARP；再加本机 ARP 表。有这台 LAN2 以外的 MAC 就停下、打出那个 MAC，不改地址。不是 root、或 arping 和 python3 都没有时，开头就明说「查重只看 ARP 表、查不出两台同时接着」。**现场规矩照旧：一次只插一台** |
| 两个人同时跑 / Ctrl-C 后马上再跑 | 状态目录上 `flock`（`<状态目录>/.lock`）：同时只能跑一个，第二个直接拒绝。退出（含 Ctrl-C）时把后台在推 / 在查的连子进程一起停掉，屏幕上说一句；EG 上已开始的安装照跑，之后 `--resume` 接着查（EG 上的 `install.pid` 记 pid + boot_id，EG 重启过就不会把复用的 pid 当成还在装） |
| 克隆机：主机名、主机密钥都和某台一样 | 这台以前记过 machine-id 就一定比，不一样就停下（不然会把同一个正式地址再给一台）；主机密钥和别的 SN 一样只提醒 |
| netplan 内容不合法 | 先 `netplan generate`，不过就恢复原文件、不 apply |
| 推送中断 / 子站重启 | 状态按 SN 存在 `/var/log/lsa9600sp/eg-field/<SN>/`（state、log）；重跑同一条命令时先把「改完地址但没装完」的几台在后台接着做（续传、已在装的只续查）；`--resume` 只续做不等新机 |
| 同一台再次出现在 .250 | 已待接入的：提示「已经做过」，不重做（`--redo <SN>` 才重做）；之前改地址失败的：本次运行里要 `r` 回车才重做，重启脚本后直接重做 |
| 安装失败 | `setup.sh` / `install.sh` 的输出整份拉回这台的 log；记失败，汇总给出 EG 上看什么（`install.sh --status`）、怎么重来（重跑本脚本 `--resume`，会从「装」那一步重来） |
| 时钟差太多 | 读 EG 时间，差 > 60 s：在子站主机上跑时直接把 EG 校成子站时间（子站本来就是站内时间服务器）；在笔记本上只提醒（`--set-time` 强制校） |
| 签名 / 校验 | 开始前算一次 `.run` 的 sha256（旁边有 `.sha256` 就对一下）；子站有 `/opt/lsa9600sp/release-signers` 且有 `.sig` 就先验签，不对整批不开始；EG 上收完再比 sha256；`.run` 自己解包后还会 `sha256sum -c` |

**日志**：屏幕上每台每个阶段一行；`run-<时间>.log` 是这一次会话的全部屏幕输出；每台一份 `<SN>/log`（含 EG 上 setup.sh / install.sh 的完整输出）；`--status` 打全表现状（SN、单元、地址、阶段、说明）。

## 6. 子站主机 / 维护笔记本的准备

- 要能到达 `192.168.1.250`：子站主机通常在站内网段（如 192.168.10.x），没有到 192.168.1.0/24 的路由。脚本开头检查，缺了就提示（或 `--temp-ip 192.168.1.251/24` 让脚本临时加、退出时删）：
  `sudo ip addr add 192.168.1.251/24 dev <接站内交换机的网口>`
- 每换一台，脚本先清掉 `.250` 的 ARP 缓存（`ip neigh flush to 192.168.1.250`，要 root；不是 root 时等它自己过期，最多十来秒）。
- 维护笔记本也能跑：Linux 或 WSL（要 bash、ssh、ssh-keygen、sha256sum），加 `--join-key '<子站那一行>'`；不是 root 时状态放 `~/.lsa9600/eg-field/`。在子站主机上不给 `--join-key` 时自动取 `join-egs.sh --keygen` 的那一行。
- **站内网段还没定**（2026-10-20 用户答复）：脚本里不写死任何站内网段，LAN2 正式地址 / 前缀 / 网关一律从分配表（或 `--gw`）读，不给就拒绝；只有出厂临时地址 `192.168.1.250/24` 是定的（厂家手册 v1.1，`LSA_FIELD_TEMP` 可改）。
  - 站内网**不在** 192.168.1.x：子站主机 / 笔记本加临时地址（`--temp-ip 192.168.1.251/24`）。
  - 站内网**就在** 192.168.1.x：`.250` 不能分给任何设备（分配表写了直接拒绝，开头还会提醒）；新机的 `.250` 可能和站内别的设备撞（已上线的 EG 不会占 `.250`，但摄像机出厂、别家设备可能），所以**建议上架装软件时新机接单独的交换机或笔记本直连**，不接已上线设备的站内网；脚本每台改地址前查 `.250` 有没有重复（§5），正式地址被占也会停下。

## 6a. 用法速查（实现后）

| 命令 | 做什么 |
|---|---|
| `--plan <表> --run <.run> [--temp-ip 192.168.1.251/24] [--parallel 3]` | 连续做：等 .250 → 改地址 → 后台装；q 回车结束（等后台做完、汇总） |
| `… --yes` | 每台不再问「回车开始改地址」（缺省每台确认一次） |
| `… --once [--sn <SN>]` | 只做 .250 上这一台，前台做完（主机名不是 `lsaeg-<SN>` 的用 `--sn`） |
| `… --count N` | 做满 N 台就结束 |
| `--plan <表> --readdress-only` | 只改地址（安装文件还没到）；之后 `--run <.run> --resume` 再装 |
| `--plan <表> --run <.run> --resume` | 不等新机，把改好地址、没装完 / 装失败的接着做（推送续传；EG 上已在装的只续查） |
| `--plan <表> --status` | 全表现状 |
| `--redo <SN>` | 清掉这台的记录与钉住的主机密钥（换机、重装系统） |
| `--gw <网关>`、`--lan1-addr none`、`--set-time` / `--no-set-time`、`--keep-run`、`--state-dir <目录>` | 见 `--help` |

- 屏幕：每台每个阶段一行 `时间 [SN] …`；等 .250 时 `q` 回车结束、`r` 回车 = 刚才停下的那台修好了、重做。
- 一台在 .250 上停下（SN 不在表里、LAN1 对不上、正式地址被占、主机密钥变了…）时脚本不会反复重试：拔掉它或输入 `r` 才看下一台。改地址后连不回来的那台 180 s 后自己回到 .250，也要 `r` 才重做（分配表改了要重启脚本，表只在开头读）。
- 退出码：这一次做过的有失败就是 1。
- 在 EG 上留下的：`/etc/netplan/50-lsa-eg.yaml`（600）、`/var/lib/lsa-field/`（出厂 netplan 原文件 `netplan.orig/`、每次改地址的备份、安装日志 `install.log`）。

## 7. 范围外（这次不做）

- 自动接着跑 `join-egs.sh`（接入要单元号定好、传感器参数等，现场节奏和装软件不一样）：本脚本只写出 join 清单、打印下一步命令。之后需要再加 `--join`。
- 改 `lsaadmin` 口令、关 SSH 口令登录：接入后的安全收尾，另说。
- Windows 原生跑（只支持 Linux / WSL）。

## 8. 测试计划（沙箱，不下载任何东西）

本机没有带 sshd 的镜像、也不能下载 openssh，所以分两段：

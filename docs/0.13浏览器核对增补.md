## 测试留下的痕迹（不是问题）

- AH12 电表事件里有两条「倍率变更」：CT 1 → 40、CT 40 → 1，由 admin 登记，都是 10-10 验收时临时改变比留下的。
- AH11 能力页的历史里有 tev / uhf 打开再关、pm6 改 pending / unsupported / confirmed 再退回的记录。这些都是端到端测试做的，最后都已回到 model 缺省。
- 临时把 AH12 的 CT 设成 40 时，EG 上送的电流和功率都乘了 40。如果那段时间的趋势或日电量里有尖峰，就是这次测试造成的。

## 已知问题（已报后端，不算核对失败）

- 子站实时点表：`us.cnt` 的单位还显示「次/min」；`tev.amp` / `uhf.amp` 没有名称和单位，名称直接显示成 key。数值是对的，原因是 ext 自己写死了单位表。
- EG 从 0.3.x 升到 0.4 后，子站不会自动重发配置。配了变比的柜子要在网关页手动点一次「下发配置」，「变比未生效」的提示才会消失。

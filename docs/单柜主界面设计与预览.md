# 单柜主界面设计与预览

日期：2026-09-27（原稿：领导 80e01ad「完善边缘网关单柜界面、传感器演示和预览文档」；同日 eg-ui-v2 **已接真实接口**，本稿随之修订）

## 设计基线

参考子站前端 `lsa-9600sp` 的单柜页面，复用双光播放器、温湿度表、ECharts 图表主题与多单位趋势图。移除了组件对子站数据仓库的依赖，并将播放器所需的全局布局样式移入组件内部。

边缘网关默认进入“本柜总览”。侧栏提供本柜总览、电气量、事件与录像、设备与通信。原有的管理页（服务状态、实时数据、下挂设备、视频与测温、证据、诊断、日志、系统）全部保留，挂在「设备与通信」下做子页（`#/manage/…`，旧地址自动跳转）。

## 页面内容（真实数据的来源见下表）

- 总览：顶部柜体信息、事件摘要（级别最高、最新的一条活动告警）、并排双光实况、R1/R2/R3 测温区（按摄像机坐标画框，最热的标黄）、最高温与温升、柜内温湿度指针表与趋势（多隔室时可选 SAM）、露点、局放幅值与次数的双轴图（各隔室取大）；详细事件列表由侧栏进入。
- 电气量：相电压、三相电流、功率、功率因数、频率、电能、负荷率及三相电流趋势（5 min 平均）。点表是相电压 Ua/Ub/Uc，原型里的线电压改为相电压。
- 事件与录像：本地事件（EG 本地 TB 告警）按类型筛选；「关联录像」打开该事件的证据组：双光视频并排回放、双光抓图、录波（JSON，下载查看）。
- 烟雾与弧光：颗粒物按点表 `pm` 设备的定义接入（≥1.0 μm 颗粒数 个/L、PM2.5、PM10 μg/m³），传感器型号仍待确认；弧光为各 SAM 的 `uv.pulse` 脉冲（峰值 a.u.、持续 ms）与当前 `uv.int`。点表里没有的通道显示「待确认」，不据此生成告警。
- 布局：左侧为双光画面和温湿度，右侧从上到下为局放、烟雾 / 气体、UV 弧光；常用桌面窗口整页显示，小屏允许滚动。页脚显示公司版权。
- 健康评分：不在网关独立计算或展示模拟评分。

## 已接真实接口（eg-ui-v2）

| 卡片 | 数据 | 接口 |
|---|---|---|
| 双光实况 | 可见光 / 热像子码流（常拉常录、秒开） | `POST api/stream/<柜号>-sub/whep`、`…/<柜号>-ir-sub/whep`（WebRTC），连不通退 `…/index.m3u8`（HLS）；agent 带会话鉴权反代到本机 mediamtx |
| 测温区框与读数 | 区域坐标 / 画面尺寸；`ir.R<n>.max`（点区域 `.pt`）、`ir.hot`、`ir.rmax`、`ir.rise` | `GET api/video/status`、`GET api/live/CAM-<柜号>` |
| 温湿度、露点 | `env.t`、`env.rh`（露点按 Magnus 公式在页面算） | `GET api/live/SAM-…`；趋势 `GET api/history` |
| 局放 | `us.amp`（dB）、`us.cnt`（次/min） | 同上 |
| 烟雾 / 气体 | `pm.1.0`、`pm.2.5`、`pm.10` | `GET api/live/PM6-…`、`GET api/history` |
| UV 弧光 | `uv.int`、`uv.pulse` | `GET api/live/SAM-…`、`GET api/history?agg=NONE` |
| 电气量 | `el.U*`、`el.I*`、`el.P/Q/S/PF/F/Ep`、`el.load_pct` | `GET api/live/PM-…`、`GET api/history` |
| 事件与录像 | 本地事件、关联证据、文件 | `GET api/alarms`、`GET api/evidence`、`GET api/evidence/<id>/file` |

接口的详细说明：`docs/EG本地接口.md`。取不到的量显示「—」，不回退到演示数据；实时值 3 s、趋势 60 s、测温区定义 30 s、事件 10 s 刷新。

## 预览启动

演示（不接后端）：

```powershell
npx --yes pnpm@9.15.9 --filter @lsa-eg/admin-web install --frozen-lockfile
npx --yes pnpm@9.15.9 web
```

打开 `http://127.0.0.1:8798/?demo=1#/overview`。演示模式仅在 Vite 开发服务器中启用，使用只读模拟数据（`monitor-demo.ts`），不调用实际管理接口；生产构建不会因为 `demo=1` 跳过登录。

真实数据：开发样机（`pnpm dev:up`、`dev:emu`、`dev:video`、`dev:agent`）起来后，`pnpm web` 打开 `http://127.0.0.1:8798/#/overview` 用本地维护账号登录；或者直接开 agent 直出的 `http://127.0.0.1:9100/`。

## 可操作项目

- 侧栏折叠与导航，地址哈希保留当前页面。
- 热像铁红/白热/彩虹调色（只对演示示意画面生效；实况热像的伪彩由摄像机出）、测温标注开关、全屏。
- 温湿度趋势图例开关与悬停读数；多隔室选 SAM。
- 露点解释提示。
- 电气量趋势、事件类型筛选、关联录像回放与下载、跳转设备与通信。

## 接口与限制

EG 已按后端《EG独立TB调整方案》改为独立 ThingsBoard CE（原稿写的 TB Edge 方案已不用）。温湿度表暂不新增未确认的红黄绿阈值分区；真实范围和告警规则由子站下发的配置提供。局放次数的统计周期按点表（次/min）。颗粒物与弧光传感器型号待确认，确定后只改点表与单位。

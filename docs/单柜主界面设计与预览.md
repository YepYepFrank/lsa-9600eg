# 单柜主界面设计与预览

日期：2026-09-27

## 设计基线

参考子站前端 `lsa-9600sp` 的单柜页面，复用双光播放器、温湿度表、ECharts 图表主题与多单位趋势图。移除了组件对子站数据仓库的依赖，并将播放器所需的全局布局样式移入组件内部。

边缘网关默认进入“本柜总览”。侧栏提供本柜总览、电气量、事件与录像、设备与通信。原有服务状态、总线状态、诊断与维护逻辑保留在设备与通信页。

## 页面内容

- 总览：顶部柜体信息、事件摘要、并排双光图像、R1/R2/R3 标记、最高温与温升、柜内温湿度指针表与趋势、露点提示、局放幅值与设备次数的双轴图；详细事件列表由侧栏进入。
- 电气量：电压、电流、功率、频率、电能等演示读数及三相电流趋势。
- 事件与录像：事件类型筛选；录像服务未接入时明确显示待接入，不提供虚假的播放链接。
- 烟雾与弧光：演示模式下展示 PM1.0、PM2.5、PM10 三通道读数与趋势，以及 UV 弧光峰值相对强度、24 小时脉冲次数和脉冲图。PM 通道是临时界面示例，不代表已经确定的烟雾传感器；弧光强度使用任意单位 a.u.。型号确定后调整字段、单位、量程和协议，当前不据此生成实际告警。普通模式仍显示待接入。
- 布局：左侧为双光画面和温湿度，右侧从上到下为局放、烟雾 / 气体、UV 弧光；常用桌面窗口整页显示，小屏允许滚动。页脚显示公司版权。
- 健康评分：不在网关独立计算或展示模拟评分。

## 预览启动

在仓库根目录执行：

```powershell
npx --yes pnpm@9.15.9 --filter @lsa-eg/admin-web install --frozen-lockfile
npx --yes pnpm@9.15.9 web
```

打开 `http://127.0.0.1:8798/?demo=1#/overview`。

演示模式仅在 Vite 开发服务器中启用，使用只读模拟数据，不调用实际管理接口。普通地址继续使用原有登录；生产构建不会因为 `demo=1` 跳过登录。

## 可操作项目

- 侧栏折叠与导航，地址哈希保留当前页面。
- 热像铁红/白热/彩虹调色、测温标记开关、全屏。
- 温湿度趋势图例开关与悬停读数。
- 露点解释提示。
- 电气量趋势、事件类型筛选、跳转设备与通信。

## 接口与限制

新监测页面目前为界面原型。普通模式在监测接口未实现时显示待接入，不回退至模拟数据。既有管理页继续使用原仓库的 `status`、`components`、`diag` 等接口。

原仓库后台采用 TB Edge 的方案，而此前子站交接方案约定两端独立 ThingsBoard CE/PE，两者存在架构差异。本次只调整界面，不修改现有后台；正式接入前需与同事统一协议及服务分工。

温湿度表暂不新增未确认的红黄绿阈值分区；真实范围和告警规则应由经确认的配置提供。局放次数的统计周期仍待确认。生产视频、测温、电表、事件与录像接口需要分别联调。

## 验证

- 前端类型检查与生产构建。
- 浏览器检查默认首页、调色、标记、图例、电气量、事件筛选、管理页、普通模式登录。
- 演示过程无后台 API 请求、无页面脚本错误。
- 检查 1450、1922 及 850 像素宽度下的布局；小屏采用纵向滚动。

模拟数据集中在 `apps/admin-web/src/monitor-demo.ts`；开发预览入口在 `session.ts` 中受开发模式限制。后续接入真实设备时保留演示与生产数据的隔离。

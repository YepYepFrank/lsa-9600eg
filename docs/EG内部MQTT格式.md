# LSA-9600EG · EG 内部 MQTT 格式 v0.2

> **读者**：把各传感器数据转成 MQTT 的同事（转换程序跑在 EG 上）。
> **用途**：转换程序往 EG 本机的 MQTT 服务发什么、发到哪、多久发一次。按这里发，数据就能经 EG 上的 TB IoT Gateway 进 EG 本地 TB、再由 eg-agent 上送子站，子站不用改。
> **依据**：点表与周期同《EG / SAM 接入规范》§5–§6（后端仓库 `docs/EG_SAM接入规范.md`）；机读版在 `@lsa/points` 的 `catalog.ts`，本文与它不一致时自检会报错。
> **参考实现**：`packages/emu`（开发用的仿真器，就是按本文发的）。
>
> 状态：v0.2（2026-09-27）。改动记在文末「修订记录」。

## 1. 数据怎么走

```
传感器 ──串口 / 网口──► 转换程序（同事）──MQTT──► EG 本机 Mosquitto（127.0.0.1:1884）
                                                      ├──► TB IoT Gateway ──► EG 本地 TB（存 7 天、算本地告警）
                                                      └──► eg-agent（算负荷率、看护数据质量、EG 自身指标、南向统计；上送子站）
```

转换程序**只和本机 Mosquitto 打交道**，不连本地 TB、不连子站。断网、补传、告警都由后面的环节处理。

## 2. 连接

| 项 | 值 |
|---|---|
| 地址 | `mqtt://127.0.0.1:1884`（EG 本机；开发机上是 `127.0.0.1:11883`） |
| 账号 | 不鉴权：本机总线只绑 127.0.0.1（摄像机网、上行网都连不到），不用账号 |
| 协议 | MQTT 3.1.1 或 5 均可 |
| QoS | **1** |
| retain | **不要用** |
| clientId | 固定且唯一，如 `lsa-conv-AH03` |
| keepalive | 30 s；断开后 3 s 内重连 |

## 3. 主题

| 主题 | 用途 |
|---|---|
| `lsa/<设备名>/telemetry` | 遥测（读数） |
| `lsa/<设备名>/attributes` | 静态属性（上电、重连后各发一次） |

**设备名**必须与子站一致，以这台 EG 的 `eg.yaml` 为准（本地管理页「设备」里有列表）。规则：

| 设备 | 设备名 | 例 |
|---|---|---|
| 感知模块 SAM（每隔室一台） | `SAM-<柜号>-<隔室字母>` | `SAM-AH03-B` |
| 多功能电表 | `PM-<柜号>`，第二块 `PM2-<柜号>` | `PM-AH03` |
| 颗粒物 / 烟气传感器 | `PM6-<柜号>` | `PM6-AH03` |
| EG 本身（EG 级信号，§5.4） | `EG-<柜号>` | `EG-AH03` |

隔室字母按柜型的隔室顺序：中压开关柜 A 断路器室 / B 电缆室；干式变压器 A 线圈正面 / B 线圈背面 / C 高低压进出线；低压柜 A 电缆室。

不在清单里的设备名**不会上送**（本地管理页会提示「总线上有不在设备清单里的设备名」）。

## 4. 载荷

```json
{"ts": 1790155214000, "values": {"ir.t_max": 82.4, "ir.t_avg": 70.1, "ir.rise": 55.9}}
```

- `ts`：**采样时刻**，毫秒，EG 本机时钟（EG 已对时，见接入规范 §9）。不要用发送时刻。
- `values`：本周期这台设备的全部量打成**一条**，不要一个值一条。
- 数值发数值（`82.4`，不是 `"82.4"`）；标注「JSON 字符串」的量发字符串化的 JSON。
- 一次发多个时刻可以用数组：`[{"ts":…,"values":{…}}, {"ts":…,"values":{…}}]`。
- **采不到的量不要发 0、不要重复上次的值 —— 直接不发这个 key**。eg-agent 按周期判断：超过 3 个周期没来标「陈旧」，超过 30 s（或 5 个周期）标「无效」，子站据此显示并扣分（§6）。
- 周期是上限：**数值没变也要按周期发**（子站靠它判断数据新鲜、设备在线）。

## 5. 各类设备发什么

周期档：**快 2 s**、**慢 10 s**、**分钟 60 s**。

### 5.1 SAM（每隔室一台）

| key | 含义 | 单位 | 周期 | 说明 |
|---|---|---|---|---|
| `ir.t_max` | 红外最高温（全画面） | ℃ | 快 | |
| `ir.t_avg` | 红外平均温 | ℃ | 快 | |
| `ir.rise` | 温升 | K | 快 | = 本隔室最高温 − 本隔室环境温度 `env.t` |
| `ir.box.A` `ir.box.B` `ir.box.C` | 各框最高温 | ℃ | 快 | 低压柜另有 `ir.box.N`；框的定义见属性 `ir.boxes` |
| `us.amp` | 超声局放幅值 | dB | 快 | |
| `us.cnt` | 超声局放次数 | 次/min | 快 | |
| `uv.int` | 紫外弧光强度 | — | 快 | **没有放电也要每 2 s 发背景值**（弧光告警靠它恢复） |
| `uv.pulse` | 弧光脉冲 | — | 事件 | 检测到放电**立即**发一条：`uv.int` = 峰值，同时带 `uv.pulse` = `"{\"peak\":463,\"ms\":21}"`（JSON 字符串：峰值、持续毫秒） |
| `env.t` | 隔室环境温度 | ℃ | 慢 | |
| `env.rh` | 隔室相对湿度 | % | 慢 | |
| `ir.z01` … `ir.z24` | 分区测温（可选） | ℃ | 慢 | SAM 支持分区时才发 |

属性：`fw` 固件版本；`ir.boxes` 分框定义（JSON 字符串，格式见接入规范 §5）。

### 5.2 多功能电表

| key | 含义 | 单位 | 周期 |
|---|---|---|---|
| `el.Ua` `el.Ub` `el.Uc` | 相电压 | V | 快 |
| `el.Ia` `el.Ib` `el.Ic` | 相电流 | A | 快 |
| `el.P` `el.Q` `el.S` | 有功 / 无功 / 视在功率 | kW / kvar / kVA | 快 |
| `el.PF` | 功率因数 | — | 快 |
| `el.F` | 频率 | Hz | 快 |
| `el.Ep` | 正向有功电能（累计，必须单调不减） | kWh | 快 |
| `el.THDu` `el.THDi` | 电压 / 电流总谐波畸变率 | % | 快 |
| `el.hu.A` `el.hu.B` `el.hu.C` | 电压 2–31 次谐波含有率（JSON 字符串，30 个数） | % | 分钟 |
| `el.hi.A` `el.hi.B` `el.hi.C` | 电流 2–31 次谐波含有率（JSON 字符串，30 个数） | % | 分钟 |

三相电流**放在同一条消息里**：负荷率由 eg-agent 按同一时刻的三相电流算。属性：`fw`。

### 5.3 颗粒物 / 烟气传感器

| key | 含义 | 单位 | 周期 |
|---|---|---|---|
| `pm.0.3` `pm.0.5` `pm.1.0` | 粒径 ≥ 0.3 / 0.5 / 1.0 μm 的颗粒数 | 个/L | 慢 |
| `pm.2.5` `pm.5.0` `pm.10` | PM2.5 / PM5.0 / PM10 质量浓度 | μg/m³ | 慢 |

### 5.4 EG 级信号（设备名 `EG-<柜号>`）

| key | 含义 | 取值 | 周期 |
|---|---|---|---|
| `sw.cb` | 断路器分合位 | `1` 合 / `0` 分 / `-1` 位置不明 | 变位立即 + 分钟 |
| `sw.es` | 接地刀位置（可选） | 同上 | 同上 |
| `eg.power` | 装置电源 | `0` 正常 / `1` 主电源失电 | 变化立即 + 分钟 |

这几个量子站还没接（接入规范 §12「子站待实现」）；先按这里发，子站做好就能用。

## 6. 不要发的量（eg-agent 算）

| key | 谁发 | 说明 |
|---|---|---|
| `el.load_pct` 负荷率 | eg-agent | = max(Ia, Ib, Ic) ÷ 额定电流 × 100，额定电流在子站配置 |
| `eg.*` EG 自身指标 | eg-agent | CPU、内存、存储、对时偏差、到子站时延等 |
| `q` 质量码 | eg-agent | 按周期看护自动标出。**你明确知道某个量坏了**（如传感器报故障码）可以自己发 `q`，eg-agent 会与看护结果合并：`"q": "{\"env.t\":\"invalid\"}"`，取值 `invalid` / `stale`，好了发 `"{}"` |
| `dev.req_24h` `dev.timeout_24h` `dev.rate_24h` 南向统计 | eg-agent | 按数据到达情况算。**你那边有真实的串口统计**（请求、超时、校验错、重试）可以自己发，某台设备只要你发了任何一个 `dev.*`，eg-agent 就不再替它发 —— 那就五个一起发：再加 `dev.crc_24h` `dev.retry_24h` |
| `cam.*` 视频指标 | eg-video | 视频不经你的程序 |
| 设备属性里的隔室、端口、协议、额定电流 | eg-agent | 按子站下发的 `eg.yaml` 发；你发的 `fw`、`ir.boxes` 等会覆盖同名项 |

## 7. 示例

```bash
# SAM 快档（2 s 一条）
mosquitto_pub -h 127.0.0.1 -p 1884 -q 1 -t lsa/SAM-AH03-B/telemetry \
  -m '{"ts":1790155214000,"values":{"ir.t_max":82.4,"ir.t_avg":70.1,"ir.rise":55.9,"ir.box.A":70.2,"ir.box.B":82.4,"ir.box.C":70.5,"us.amp":12.3,"us.cnt":4,"uv.int":3}}'

# 弧光放电（立即）
mosquitto_pub -h 127.0.0.1 -p 1884 -q 1 -t lsa/SAM-AH03-B/telemetry \
  -m '{"ts":1790155215123,"values":{"uv.int":463,"uv.pulse":"{\"peak\":463,\"ms\":21}"}}'

# 断路器合位
mosquitto_pub -h 127.0.0.1 -p 1884 -q 1 -t lsa/EG-AH03/telemetry -m '{"ts":1790155216000,"values":{"sw.cb":1}}'

# 看自己发出去的与 eg-agent 发的
mosquitto_sub -h 127.0.0.1 -p 1884 -v -t 'lsa/#'
```

## 8. 怎么确认发对了

1. 本地管理页（浏览器开 `http://<EG 上行口 IP>/`）：每台设备的测点数、最近数据时刻、状态「正常」，质量码为空；
2. 子站「边缘网关 → 该网关 → 实时数据」：各量有值、质量「有效」、设备时间与到达时间相差 < 3 s（接入规范 §14）。
